# PCIE Test Plan (Stage1) Fallback Automation\n\nThis repository now includes a deterministic GitHub Actions workflow and Python script to generate the Stage1-formatted PCIE Test Plan Excel (.xlsx) from embedded JSON.\n\n- Workflow: `.github/workflows/generate_pcie_testplan.yml`\n- Script: `scripts/gen_stage1_testplan_excel.py`\n\nThe workflow runs on push to either of the above paths. It will:\n- Set timezone to IST (Asia/Kolkata)\n- Generate `Test_Output/PCIE/TestPlan/PCIE_TestPlan_<YYYYMMDD>_<HHMMSS>.xlsx`\n- Commit only the finalized Excel with commit message: \n  `Add PCIE Test Plan (Stage1) autogenerated on <IST YYYY-MM-DD HH:MM:SS>`\n\nNote: Macro names found in content are replaced with canonical register names where possible by scanning repo header `#define`s and canonicalizing prefixes/suffixes. A mapping is stored in the very hidden `Meta_data_sheet`.\n
