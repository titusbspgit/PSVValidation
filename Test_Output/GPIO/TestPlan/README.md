```bash
# Run the script
python generate_GPIO_TestPlan.py
```

1. Creates a real `.xlsx` workbook with:

2. Pushes the `.xlsx` file to `Test_Output/GPIO/TestPlan/` on the `main` branch
3. Prints the commit SHA and GitHub URL
