# SPI Test Plan Outputs

This directory contains the auto-generated SPI Test Plan in Excel format.

Files:
- SPI_TestPlan_latest.xlsx: Rolling latest test plan.
- SPI_TestPlan_YYYYMMDD_HHMMSS.xlsx: Timestamped snapshot (IST) generated by GitHub Actions.

How it works:
- On changes to `tools/generate_spi_testplan.py` (or manual dispatch), a workflow generates the .xlsx using `openpyxl` and commits it here.

Source inputs (discovered test items):
- TestRepo/spi/spi_pio_full_duplex
- TestRepo/spi/spi_pio_rx_dma_tx
- TestRepo/spi/spi_reg_wr_rd_test
